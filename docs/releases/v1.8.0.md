Desktop Buddy 1.8.0 is released for Linux x86_64. This release was built and
checked locally; publishing does not use GitHub Actions runners.

Download **desktop-buddy-1.8.0-linux-x86_64.tar.gz** for the standalone app.
It includes Python and Qt. Supported baseline: Ubuntu 24.04 or newer,
x86_64, glibc 2.39+. Linux/X11 provides full window control; Wayland runs with
reduced positioning, perching and click-through capabilities.

```bash
tar -xzf desktop-buddy-1.8.0-linux-x86_64.tar.gz
cd desktop-buddy
./desktop-buddy              # portable launch
# Or install for your user:
./install.sh                 # add --no-autostart to skip login startup
```

Features include Bolt, Boo-ombastic and Mochi, seven themes, desktop animation
and perching, local custom reminders, safe quick actions, a persistent focus
timer, permissioned plugins, opt-in context awareness, Linux media controls,
and a read-only local calendar integration.

The installer adds an application-menu entry and login startup without requiring
Python or downloads. Settings and history survive upgrades; uninstall preserves
them unless `--purge` is selected. Standalone autostart correctly launches the
packaged executable, including paths with spaces.

Python wheel and source packages are also attached. `SHA256SUMS` verifies the
four release assets; `BUILD_INFO.json` records the source commit and dependency
versions. Verify downloaded assets together with `sha256sum -c SHA256SUMS`.

Windows releases are deferred. Windows backend/packaging source is retained,
but no Windows installer is published. Signing and real Windows 10/11 mixed-DPI
validation remain incomplete.

Future releases use the local build and GitHub CLI upload commands in
[the release guide](https://github.com/rajm012/Desktop-Buddy/blob/v1.8.0/docs/RELEASING.md).
Automatic Actions runs are paused; optional hosted checks are manual and
Linux-only.
