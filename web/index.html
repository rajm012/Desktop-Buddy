NEXT, SAY HELLO

Unpack. Install. Enjoy.

Extract the archive and run ./install.sh to add your buddy to the application menu and start it at login. No Python setup needed.

Just trying it out? Run ./desktop-buddy from the extracted folder.

Quick start
tar -xzf desktop-buddy-1.8.0-linux-x86_64.tar.gz
cd desktop-buddy
./install.sh

Add --no-autostart to skip login startup.

Using Wayland? The buddy runs with reduced positioning, perching, and click-through. Use an X11 session for the full experience. See Linux tips ↗
